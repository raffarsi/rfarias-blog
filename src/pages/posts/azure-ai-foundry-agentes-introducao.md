O Azure AI Foundry unifica desenvolvimento e implantacao de aplicacoes de IA. Consolida Azure OpenAI Studio, Azure ML e Cognitive Services.

## Quando usar AI Foundry vs API direta

Use AI Foundry para equipes grandes, Prompt Flow, avaliacao automatizada e Model Catalog. Use API direta para aplicacoes simples com um desenvolvedor onde latencia e critica.

## Conclusao

Para novos projetos de agentes de IA com equipes maiores, o AI Foundry e o ponto de partida recomendado.
